P2P Advisor Agent (CrewAI)

Overview

Prototype multi-agent workflow designed to demonstrate Procure-to-Pay (P2P) automation concepts.

Agents

1. Data Extraction Agent
2. Validation Agent (3-way matching)
3. Decision Agent

Workflow

Invoice → Extraction → Validation → Decision → Output

Sample Output

Invoice: INV_1002
Status: Approved
Reason: No discrepancies found
Action: Proceed with payment

Skills
